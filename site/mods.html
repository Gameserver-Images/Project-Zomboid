Project Zomboid server mods

Env varsMods

Picks, orders and configures the workshop mods of a server running the ghcr.io/gameserver-images/project-zomboid image. Load what docker exec <container> list-mods prints, then copy the .env lines this page builds. Nothing leaves your browser.

Load your server's mods

Start the server once so it downloads its mods, run docker exec <container> list-mods > mods.json, then choose the file, drop it anywhere on this page or paste its contents.

Loading a file starts over from that server's settings.

Import an existing .env

Paste your env file. INI_Mods sets the enabled mods and their order; SANDBOX_ values of these mods, the INI_ settings their workshop pages ask for, INI_Map and WORKSHOP_IDS replace the ones here. Other lines are ignored.

Puts requirements and loadModAfter/loadModBefore first, then follows the band order.
